# Auction System

## Description
The Auction System is a Java application that simulates a simple bidding process. Users can enter their names and bids, and the system automatically tracks the highest bid and the highest bidder. It is a basic yet functional tool to understand auction mechanics and implement Java programming concepts.

## Features
- Add multiple bidders
- Input bid amounts for each participant
- Automatically determine the highest bid
- Display the highest bidder and their bid
- Simple and interactive console-based interface
